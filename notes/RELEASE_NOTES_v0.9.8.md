# TraeJumper v0.9.8 Release Notes

发布日期：2026-08-19

## 🎉 版本概述

本版本是 **设置页信息架构整合 + 工具栏统一化** 的迭代更新。将分散的「目标客户端」和「机器码」卡片合并为单一「客户端」卡片，动态同步窗口标题与客户端徽章，并对工具栏操作按钮进行分组重构，显著提升账号管理效率和界面一致性。

## ✨ 新功能

### 1. 设置页「客户端」卡片合并
- 原「目标客户端」+「机器码」两个独立卡片合并为单一「客户端」卡片
- 三分组布局：目标客户端选择 / 安装路径 / 机器码
- 切换客户端时，安装路径和机器码自动跟随更新，无需手动修改

### 2. 窗口标题动态同步
- 窗口标题栏实时显示当前选中的客户端名称
- 示例：`TraeJumper · Trae CN` / `TraeJumper · TRAE WORK`

### 3. 工具栏新增「切换账号」按钮
- 选中单个账号后可直接从工具栏点击切换，无需右键菜单

### 4. 操作按钮统一管理
- 删除过期 / 导入账号 / 导出账号合并为下拉菜单
- 移至工具栏最右侧，采用纯图标样式，界面更简洁

## 🎨 UI/UX 优化

### 工具栏按钮颜色区分
- 切换账号（主题蓝）、刷新（默认灰）、删除（危险红），语义清晰

### 下拉菜单防遮挡
- 使用 React Portal 渲染，彻底解决菜单被 toolbar 裁剪的问题

### 账号管理界面客户端标识
- 标题栏右侧显示当前客户端徽章，Dashboard 概览页同步展示

## 🔧 技术改进

- 无显著后端变更，主要为前端信息架构与交互优化
